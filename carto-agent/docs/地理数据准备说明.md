# 地理数据准备说明（本地精确数据优先）

系统采用 **本地精确 GeoJSON → OSM 实时抓取 → 兜底近似** 三级数据架构。
当 `backend/data/geo/` 下存在本地数据文件时，行政图（及含水系/路网的图）
优先使用本地精确数据，避免手绘兜底水系“不精确、随意排布”的问题。

## 一、数据目录与文件约定

目录：`backend/data/geo/`

| 文件 | 内容 | 格式 |
| :-- | :-- | :-- |
| `wuhan_districts.geojson` | 武汉 13 区县政区面（行政图必需，recall=1.0 依据） | GeoJSON, WGS84 |
| `hubei_province.geojson` / `hubei_cities.geojson` | 湖北省域 / 地级市边界（行政图周边上下文） | GeoJSON, WGS84 |
| `wuhan_water.geojson` | 河流（LineString）+ 湖泊（Polygon/MultiPolygon），含面积属性 | GeoJSON, WGS84 |
| `wuhan_riverlines.geojson` | 河流中心线（主要/支流分级） | GeoJSON, WGS84 |
| `wuhan_roads.geojson` | 道路（LineString，properties.highway 分级） | GeoJSON, WGS84 |
| `wuhan_tourism.geojson` | 旅游 POI（景点/博物馆/公园等分类） | GeoJSON, WGS84 |
| `wuhan_transit.geojson` | 轨道交通线路（LineString）+ 站点（Point） | GeoJSON, WGS84 |
| `wuhan_builtup.geojson` | 居民地/街区面（制图综合：合并/化简/分级） | GeoJSON, WGS84 |
| `wuhan_contours.geojson` | 等高线（计曲线 100m / 首曲线 20m，SRTM 30m DEM 生成） | GeoJSON, WGS84 |
| `wuhan_peaks.geojson` | 山峰点（名称 + 高程 + importance） | GeoJSON, WGS84 |

每个数据集同级存放 `<名称>.metadata.json`（来源/时间/CRS/质量/处理记录，
见 `backend/app/core/dataset_metadata.py`），进入制图流程前经 DataQualityEngine 校验。

坐标必须为 **WGS84 (EPSG:4326)**；若来自 CGCS2000/GCJ-02 请先投影转换，
否则会整体偏移（使用 GDAL `ogr2ogr` 或 geopandas `to_crs('EPSG:4326')`）。

## 二、自动化生成（推荐，一条命令）

本机执行（需安装 Python）：

```bash
cd backend
pip install osmnx geopandas
python scripts/prepare_local_geo.py
```

脚本会自动下载武汉市水系与路网，导出到 `backend/data/geo/`，
重启后端后系统自动优先使用。全量数据流水线见 `tools/run_data_pipeline.py`
（prepare_local_data → prepare_local_geo → clean_water_data → optimize_geo_data）。

## 三、手动准备（QGIS + GDAL 流程）

1. 数据源：
   - 行政区划：阿里 DataV GeoAtlas（GeoJSON，民政部数据）
   - 水系/路网：Geofabrik 下载 `china-latest.osm.pbf` 或用 OSM 范围导出
2. 裁剪出武汉市范围，坐标转 WGS84：
   ```bash
   ogr2ogr -t_srs EPSG:4326 -clipdst 113.9 30.1 114.9 31.3 wuhan_water.geojson china_water.shp
   ```
3. 按上文目录约定命名放入 `backend/data/geo/`。

## 四、矢量切片（大路网可选，性能优化）

如果路网数据很大，可先用 tippecanoe 切片为 MVT，前端用
`Leaflet.VectorGrid` 加载（后续版本支持）；当前版本直接读取 GeoJSON 已可满足市级路网。

## 五、验证

- 后端日志出现 `[LocalGeo] 使用本地水系数据: N条河流, M个湖泊` 即表示本地数据已生效。
- 未准备本地数据时，系统自动回退 OSM（成功则真实数据）/ 兜底近似（两者都失败）。
- 数据质量：`tools/run_map_qa.py` / `tools/audit.py` 对生成地图输出十项指标验收报告。
