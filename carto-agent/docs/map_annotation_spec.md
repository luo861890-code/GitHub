# 地图文字注记规范（详细版·含摆放规则）

> 本文档为 CartoAgent 制图系统的注记标准，适用于所有地图类型的文字注记生成与摆放。
> 代码实现位置：`backend/app/core/label_spec.py`、`backend/app/services/map_service.py`、`frontend/vue-app/public/legacy/map.js`。
> 屏幕图可读性底线：最小字号不小于 9px（印刷图 7-8pt）。

---

## 一、居民地注记

### 分级与字体字号
| 等级 | 字体 | 字号（相对） | 字色 |
|---|---|---|---|
| 首都/直辖市 | 粗宋体 | 最大（如20pt） | 红或黑 |
| 省/自治区 | 粗宋体 | 大（18pt） | 红或黑 |
| 地级市 | 宋体 | 中（16pt） | 黑 |
| 县/县级市 | 宋体 | 中偏小（14pt） | 黑 |
| 乡镇/街道 | 细等线 | 小（12pt） | 黑 |
| 村庄/自然村 | 细等线/细宋体 | 最小（10–11pt） | 黑 |

### 摆放规则
- **水平排列**，字头朝上，是居民地注记唯一允许的排列方式
- **位置优先级**：居民地符号（圈/点）的正上方 > 右上方 > 右方 > 左上方 > 左方 > 下方
- 注记与符号之间留 **0.2–0.5mm** 空隙，不紧贴也不远离
- 注记**不得压盖**居民地符号本身、主要道路、河流
- 密集区（如城市群）：高等级注记优先占位，低等级村庄可适当缩小字号或省略
- 同一居民地有全称和简称时，图面够用放全称，拥挤时用简称并在图例说明
- 居民地注记**不得跨河、跨主要道路**放置，避免指代歧义

## 二、水系注记

### 分类与字体
| 类型 | 字体 | 字色 | 排列 |
|---|---|---|---|
| 海洋/海湾 | 左斜宋体/隶书 | 深蓝 | 屈曲/雁行 |
| 湖泊/水库 | 左斜宋体 | 蓝 | 水平（小湖）/雁行（大湖） |
| 河流（常年） | 左斜宋体 | 蓝 | 屈曲排列，沿河走向 |
| 河流（时令/消失） | 左斜宋体 | 浅蓝 | 屈曲排列 |
| 运河/沟渠 | 左斜宋体/等线 | 蓝 | 雁行/水平 |
| 瀑布/泉/井 | 等线 | 蓝 | 水平 |
| 岛屿/半岛 | 宋体/等线 | 黑 | 水平 |

### 摆放规则
- **字向**：字头朝向河流上游方向（即从下游往上游读），或字头朝北；不可倒字
- **字隔**：
  - 短河（图上 <3cm）：接近字隔，集中放在中游
  - 中长河：普通字隔（字间距 1–3mm），均匀分布
  - 大河/长河：隔离字隔（字间距 >5mm），可分段重复标注名称
- **位置**：河流注记放在河道**内侧平缓处**，不压盖河岸线、桥梁、渡口
- 河流弯曲处注记随弯排列，**字的基线与河流中心线平行**
- 湖泊注记放在湖内**视觉中心**，大湖可放雁行排列沿湖岸走向，小湖水平放中心
- 海洋注记放在海域中央，大面积海域可重复标注
- 水系注记**不得压盖**水闸、堤坝、码头、桥梁等水利设施
- 河源、河口处一般不注记名称，放在中游

## 三、地貌与山地注记

### 分类与字体
| 类型 | 字体 | 字色 | 排列 |
|---|---|---|---|
| 山脉/山系 | 耸肩等线/黑体 | 棕色/黑 | 雁行，沿山脉走向 |
| 山峰/山顶 | 等线/黑体 | 黑 | 水平 |
| 山口/隘口/关 | 等线 | 黑 | 水平 |
| 沙丘/戈壁 | 耸肩等线 | 棕色 | 雁行/水平 |
| 溶洞/天坑 | 等线 | 黑 | 水平 |
| 火山 | 等线 | 红棕 | 水平 |

### 摆放规则
- **山脉注记**：沿山脉主脊线走向**雁行排列**，字隔均匀，字头朝北或朝上坡方向；放在山脊线一侧（通常南侧/东侧），不压盖等高线密集区
- **山峰注记**：水平排列，放在山峰符号（三角/点）的**上方或右上方**；高程数字放在峰名下方或符号右下方
- 山峰名称与高程数字**配套出现**，名称在上、高程在下，或名称在左、高程在右
- **山口/关隘**：注记放在山口符号的上方或一侧，不压盖通过山口的道路
- 地貌注记**不得压盖**等高线的特征点（山顶、鞍部、陡崖）、冲沟、滑坡
- 注记颜色用棕色时，注意与棕色等高线区分，可加细白描边或放在等高线稀疏处
- 长山脉可分段重复注记，每段之间间隔均匀

## 四、交通注记

### 分类与字体
| 类型 | 字体 | 字色 | 排列 |
|---|---|---|---|
| 铁路（干线/支线） | 等线/细黑 | 黑 | 水平/雁行 |
| 高速公路 | 等线加粗 | 红/黑 | 水平，沿路走向 |
| 国道/省道 | 等线 | 红/黑 | 雁行/水平 |
| 县乡道 | 细等线 | 黑 | 水平 |
| 桥梁/隧道 | 等线 | 黑 | 水平 |
| 车站/港口/机场 | 等线/黑体 | 黑 | 水平 |
| 道路编号（Gxx/Sxx） | 等线 | 白字红底/白字绿底 | 水平，放在道路符号上 |

### 摆放规则
- **道路名称注记**：沿道路走向**雁行排列**，字隔均匀，放在道路符号**上方或右侧**，不压盖道路中心线
- 短道路（图上 <2cm）可水平注记在道路一端
- 长道路可**分段重复注记**，每隔 5–8cm 重复一次路名
- **道路编号**：放在专用编号符号（盾形/矩形）内，符号压在道路线上，编号水平居中
- 注记**不得压盖**：道路交叉口、桥梁、隧道口、车站、铁路与公路交叉点
- 铁路注记放在铁路符号（黑白相间段）的**上方或右侧**，不压盖铁轨符号
- 车站注记放在车站符号的**上方或右侧**，站名与站符间距 0.3–0.5mm
- 机场注记水平放在机场符号（飞机符号/跑道轮廓）的上方或一侧
- 港口注记放在港区陆侧，不压盖码头岸线和水域

## 五、行政区域与境界注记

### 分类与字体
| 类型 | 字体 | 字色 | 排列 |
|---|---|---|---|
| 国名 | 粗宋体/黑体 | 红/黑 | 水平 |
| 省/自治区名 | 粗宋体 | 红/黑 | 水平（小省）/雁行（狭长省） |
| 市/县名 | 宋体 | 黑 | 水平 |
| 乡镇名 | 细等线 | 黑 | 水平 |
| 界桩/界碑编号 | 等线 | 黑 | 水平 |

### 摆放规则
- **行政区域名**：放在该区域的**几何中心或视觉重心**（考虑居民地分布、水域占据等因素调整），不要求严格数学中心
- 区域面积大时，注记可适当放大字号；区域狭小时，注记沿区域长轴**雁行排列**
- 注记**完全落在本区域范围内**，不得跨境界线，不得压盖境界线上的界桩、界碑
- 境界线转弯处、交会处不放置注记
- 相邻区域注记之间留足间距，不重叠不混淆
- 飞地、插花地的注记放在飞地范围内，面积过小可引线标注
- 国名一般只在本国范围内标注一次，放在国土中心或显著位置
- 界桩编号放在界桩符号的**右下方**，字号最小

## 六、独立地物与控制点注记

### 分类与摆放
| 类型 | 摆放位置 | 排列 |
|---|---|---|
| 三角点/水准点/GPS点 | 符号右侧或下方，点名在上、高程在下 | 水平 |
| 纪念碑/塔/亭/钟楼 | 符号上方或右上方 | 水平 |
| 庙宇/教堂/清真寺 | 符号上方或一侧 | 水平 |
| 工厂/学校/医院 | 符号上方或右侧，厂区大可放中心 | 水平 |
| 井/泉/独立树 | 符号右侧或下方 | 水平 |
| 发电站/变电站 | 符号上方或右侧 | 水平 |

### 通用规则
- 独立地物注记一律**水平排列**，字头朝上
- 位置优先：上方 > 右上方 > 右方 > 下方，**不压盖地物符号**
- 注记与符号间距 0.2–0.3mm
- 地物密集区，注记可引线标注（细实线引出，线端不超过注记首字）
- 控制点注记格式：**点名 + 高程**，点名在上，高程在下（或左名右高），高程数字精确到规范要求的小数位
- 注记不得压盖其他重要地物符号和等高线特征点

## 七、植被与土质注记

### 分类与字体
| 类型 | 字体 | 字色 | 排列 |
|---|---|---|---|
| 森林/林地 | 耸肩等线 | 深绿 | 水平/雁行 |
| 果园/经济林 | 等线 | 绿 | 水平 |
| 草地/牧场 | 耸肩等线 | 绿 | 水平/雁行 |
| 耕地/水田/旱地 | 等线 | 棕/黑 | 水平 |
| 沼泽/湿地 | 左斜宋体 | 蓝绿 | 水平/雁行 |
| 沙地/戈壁/盐碱地 | 耸肩等线 | 棕 | 水平/雁行 |

### 摆放规则
- 大面积植被/土质区：注记放在区域**中心**，雁行排列沿区域长轴
- 小面积零星分布：水平注记，放在区域内或一侧
- 注记**不压盖**植被符号（树符号、草地点符号）的密集区，放在符号稀疏处
- 植被注记与地类界保持距离，不压盖地类界
- 混合植被区（如针阔混交林）可注记混合名称，或分别注记
- 土质注记（如沙地、戈壁）放在区域中心，字号略大于植被符号

## 八、数字注记

### 分类与摆放
| 类型 | 摆放位置 | 格式 |
|---|---|---|
| 高程点（控制点） | 点符号右下方 | 数字，精确到0.1m或1m |
| 等高线高程 | 等高线平缓处，字头朝上坡 | 数字，字底贴等高线 |
| 水深 | 水域内，点旁 | 数字，单位m |
| 里程 | 道路上，公里桩旁 | 数字 |
| 桥梁跨度/载重量 | 桥梁符号旁 | 数字+单位 |
| 坐标/经纬度 | 图廓外或控制点旁 | 度分秒格式 |

### 规则
- 数字注记字号比同级名称注记**小1–2号**
- 一律**水平排列**，字头朝上（等高线高程除外，字头朝上坡）
- 等高线高程注记：放在等高线**平直段**，不放在弯曲处、闭合处；数字**字底（底部）朝向高程增加方向**（即上坡方向），数字沿等高线方向排列，不压盖等高线（可断等高线放数字）
- 高程点数字：放在点符号**右下方**，与点间距 0.2mm
- 水深注记：水深点旁，数字表示深度，一般保留一位小数
- 数字注记之间不重叠，密集区可取舍（保留特征点高程，省略一般点）

## 九、图廓整饰注记（非要素注记）

| 注记类型 | 位置 | 格式 |
|---|---|---|
| 图名 | 图廓外上方正中 | 最大字号，黑体/宋体加粗 |
| 图号/图幅编号 | 图名下方或左上角 | 等线，中等字号 |
| 比例尺 | 图廓外下方正中 | 数字+图形比例尺 |
| 指北针/三北方向 | 图廓外右上方或图内空白处 | 图形+文字 |
| 图例 | 图内空白处或图廓外右侧 | 符号+注记，注记左对齐 |
| 接图表 | 图廓外左上角 | 小格+邻图名 |
| 坐标网注记（经纬度/公里数） | 内外图廓之间，四边 | 数字，字头朝内/朝上 |
| 出版说明/编图单位 | 图廓外下方 | 小字号 |
| 坡度尺/图例说明 | 图廓外下方或左侧 | 图形+文字 |

## 十、通用摆放原则（所有注记适用）

1. **避让优先级**（被压盖时谁让谁）：
   高等级居民地注记 > 主要道路 > 河流 > 等高线 > 低等级注记 > 一般地物符号
   即：低等级注记避让高等级注记和重要地物

2. **不压盖清单**（任何注记都不能压）：
   - 居民地符号、独立地物符号
   - 道路交叉口、桥梁、隧道口、铁路公路交叉
   - 河流交汇、水闸、堤坝、码头
   - 境界线、界桩、界碑
   - 等高线特征点（山顶、鞍部、陡崖）
   - 控制点（三角点、水准点）

3. **注记间距**：
   - 注记与被注要素符号：0.2–0.5mm
   - 两条注记之间：≥0.5mm，不重叠不交叉
   - 注记与图廓：≥1mm（图内注记不贴廓线）

4. **密度控制**：
   - 注记密度以**不超过图面面积的20%–25%**为宜
   - 密集区取舍原则：取主要、舍次要；取高等级、舍低等级；取特征点、舍一般点
   - 取舍后在图例或说明中注明"本图仅标注XX以上居民地"

5. **一致性**：
   - 同一幅图内，同类要素注记的字体、字号、字色、排列方式**完全统一**
   - 同一要素在不同位置重复注记时，格式完全一致
   - 注记用字以**国务院公布的规范汉字**为准，不使用繁体字、异体字（特殊地名除外）

6. **可读性底线**：
   - 最小字号不小于 **7–8pt**（印刷图），屏幕图不小于 9px
   - 注记与背景颜色对比度足够，深色背景用浅色注记并加描边
   - 注记不旋转超过 45°（雁行排列除外，随要素走向）

## 系统落地映射（代码实现对照）

| 规范类别 | 代码位置 | 落地说明 |
|---|---|---|
| 居民地分级 | `label_spec.RESIDENCE_LABEL_BY_LEVEL` / `constants.LABEL_STYLES` | 地级市16px、区县14px、乡镇12px、村庄10-11px |
| 水系注记 | `label_spec.FEATURE_COLOR_OVERRIDE["water"]` | 深蓝 #2E6FA3 + 白描边（halo）；屏幕图保持正体横向（用户偏好），沿河方向由 rotation 表达 |
| 交通注记 | `label_spec.FEATURE_COLOR_OVERRIDE["transport"]` | 深灰 #374151，弱于道路符号 |
| 行政注记 | `label_spec.FEATURE_COLOR_OVERRIDE["admin"]` | 深灰黑 #1F2937，水平居中于面几何 |
| 地貌注记 | `label_spec.FEATURE_COLOR_OVERRIDE["peak"]` | 棕褐 #7A5230 |
| 摆放优先级 | `label/engine.py CANDIDATES` + `map.js` 偏移顺序 | 正上方 > 右上方 > 右方 > 左上方 > 左方 > 下方 |
| 不压盖 | `map.js` 碰撞检测 + `map_service._apply_label_engine` | 全局注记避让、符号碰撞、格网容量 |
| 密度控制 | `cartographic_standards.LABEL_DENSITY_LIMIT` | 按比例尺设每屏注记上限 |
| 可读性底线 | `map_service._normalize_styles` + `map.js` | 屏幕最小字号 9px |
| 一致性 | `label_spec.LABEL_STYLE` | 同级注记字体/字号/字色完全统一 |
