## 一、竞品分析与差距定位

### 1.1 DoMapAI（武大艾廷华团队）
- **核心能力**：自然语言→秒级出图，覆盖全球/国家/省/市/县区多尺度区划、地形、专题地图及地图集
- **技术路线**：DeepSeek嵌入制图链 + 地图符号语言LLM（GeoToken）+ 虚实结合场景生成
- **差距**：CartoAgent 已有 LLM+KG+工具链框架，但地图类型覆盖不足、多尺度数据不全、地形晕渲待完善

### 1.2 SuperMap AgentX
- **核心能力**：多智能体架构（规划-执行-反思），自然语言交互生成专业GIS成果，前端示例工程
- **差距**：CartoAgent 单智能体编排，缺少反思迭代闭环；前端编辑功能需对标专业GIS

### 1.3 QGIS / ArcGIS
- **核心能力**：完整工具栏（数字化/高级数字化/捕捉/标注/属性/空间分析/处理工具箱），图层样式引擎，制图整饰（布局管理器）
- **差距**：CartoAgent QgisEditor 已有基础工具栏，但缺少：形状数字化（圆/矩形/椭圆）、捕捉工具栏、标注工具、字段计算器、拓扑编辑、布局整饰面板

### 1.4 高德/百度地图 AI
- **核心能力**：POI搜索、路径规划、实时交通、车道级导航
- **差距**：CartoAgent 已有路径规划基础，但POI数据依赖OSM，缺少国内精确POI源

### 2.2 武汉市行政区划图改造要点
1. **道路精简**：仅保留 motorway（高速）、trunk（国道）、primary（省道/主干道），删除 secondary 以下
2. **行政区配色**：13区四色普染，相邻区不重复，已有 WUHAN_DISTRICT_FILLS
3. **DEM山体阴影**：新增 hillshade 底图选项，可叠加行政面（透明度调整）
4. **要素层级**：行政面（底）→水系面→道路线→行政界线→行政中心→注记（顶）
5. **注记**：按比例尺分级——zoom≥10显示区名，zoom≥12显示乡镇名
6. **禁止**：点状湖泊、点状建筑物

### 2.3 武汉市交通图改造要点
1. **主要素**：省界/市界/县界（行政骨架）+ 主要道路（高速/国道/省道/主干道）
2. **辅要素**：湖泊水系（面状）、铁路、地铁、交通枢纽（机场/车站）
3. **注记**：道路名随线标注，区县名面状居中，交通枢纽点状注记
4. **道路分级**：motorway→trunk→primary→secondary（交通图保留到次干道）
5. **禁止**：点状湖泊、点状建筑物、社区道路

## 五、地图学知识融入

### 5.1 制图综合
- **选取**：按比例尺分级选取（资格法+定额法）
- **简化**：Douglas-Peucker 线简化（已有）
- **夸张**：重要要素夸大表示
- **合并**：同类小面积合并
- **位移**：冲突要素位移避让

### 5.2 载负量控制
- 面积载负量：≤12-15%（参考地图）
- 按地图类型调整：交通图可高至18%，行政区划图≤10%
- LOD分级：zoom<8只显示省界，8-10显示市界，10-12显示县界，>12显示乡镇

### 5.3 色彩设计
- 水系：蓝色系（#1e90ff / #7dd3fc）
- 植被：绿色系（#16a34a / #86efac）
- 地貌：棕色系（#7A5230 / #C8A268）
- 行政界：紫色/红色系
- 道路：暖色系分级（红→橙→黄→灰）
- 相邻行政区：色相差≥30°，全图色彩≤8种

### 5.4 注记规范
- 名称注记：宋体/黑体，按等级分级字号
- 说明注记：小字，斜体
- 数字注记：等线体
- 注记避让：不压盖重要要素，面状注记居中
- 道路注记：随线走向排列
