# CartoAgent 项目规划与路线图

## 1. 项目定位

**CartoAgent** 是一个基于大语言模型（LLM）和知识图谱（KG）的在线地图制图智能体系统，目标是复刻 QGIS/ArcGIS 交互范式的在线地图编辑工具，让用户通过自然语言即可完成专业地图制作。

### 1.1 核心价值
- **降低制图门槛**：自然语言描述 → 专业地图输出
- **知识驱动**：制图学知识图谱保证输出符合规范
- **可编辑**：生成后可进行矢量编辑、样式调整、属性修改
- **可扩展**：支持多地图类型、多数据源、多 LLM 提供商

### 1.2 目标用户
- 地理学/GIS 专业学生和教师
- 需要快速制作地图的研究人员
- 对地图制作感兴趣的普通用户
- 需要集成制图能力的开发者

## 3. 技术架构

### 3.1 技术栈
| 层级 | 技术 | 版本 |
|------|------|------|
| 前端 | Vue 3 + Vite + TypeScript | 3.4+ |
| 地图渲染 | Leaflet + 自研 MapPanel | 1.9+ |
| 状态管理 | Pinia | 2.x |
| 后端 | FastAPI + Uvicorn | 0.115+ |
| LLM | DeepSeek API | deepseek-chat |
| 知识图谱 | Neo4j（可选） | 5.x |
| 地理数据 | OpenStreetMap + DataV GeoAtlas | - |
| 几何计算 | Shapely + PyProj | - |

## 5. 模块详细规划

### 5.1 智能体模块
**当前**：单智能体 ReAct+KG 架构
**规划**：
- 多智能体协作（制图Agent/质检Agent/编辑Agent）
- 工具调用链可视化
- 自定义工具注册
- 智能体记忆（历史会话/用户偏好）
- 多轮对话上下文管理

### 5.2 地图生成模块
**当前**：8 种地图类型，OSM+DataV 数据
**规划**：
- 支持自定义地图类型
- 更多数据源（天地图/高德/百度/Google）
- 数据融合（多源数据对齐）
- 数据质量自动修复
- 增量更新（只更新变化区域）

### 5.3 地图编辑模块
**当前**：基础矢量编辑
**规划**：
- 完整的 QGIS 编辑工具集
- 高级编辑（缓冲区/合并/裁剪/交集）
- 拓扑编辑（共享边/节点对齐）
- 批量编辑（属性/样式）
- 编辑历史和版本管理

### 5.4 注记模块
**当前**：基础注记放置，横向为主
**规划**：
- 智能注记避让（冲突检测/优化放置）
- 注记样式自定义（字体/颜色/背景/描边）
- 注记随比例尺动态调整
- 注记旋转/换行/排列方式
- 注记批量编辑

### 5.5 知识图谱模块
**当前**：基础制图知识，本地文件兜底
**规划**：
- 完整制图学本体（符号/配色/注记/综合）
- 地图案例库（优秀地图参考）
- 知识图谱可视化编辑器
- 知识推理（自动推荐制图方案）
- 知识更新和版本管理

### 5.6 质量评估模块
**当前**：基础质量检查
**规划**：
- 完整的制图规范检查清单
- 自动修复建议
- 质量评分和报告
- 对比分析（与标准地图对比）
- 持续质量监控

## 6. 数据规划

### 6.1 地理数据
- **行政区划**：DataV GeoAtlas（全国省市县）
- **道路/铁路/水系/POI**：OpenStreetMap（全球）
- **地形/DEM**：SRTM（全球，可选）
- **遥感影像**：天地图/Google（可选）
- **专题数据**：用户上传/公开数据集

### 6.2 知识数据
- 制图学规范（GB/T 系列标准）
- 地图符号库（点/线/面）
- 配色方案库（色盲友好/打印友好）
- 注记规则库
- 地图案例库

### 6.3 用户数据
- 用户地图（按用户隔离）
- 用户会话（聊天历史）
- 用户偏好（样式/语言/默认配置）
- 用户模板（自定义地图模板）

## 7. 非功能需求

### 7.1 性能
- 地图生成：中小区域 < 30 秒，大区域 < 120 秒
- 地图渲染：10 万要素 < 3 秒
- API 响应：普通请求 < 500ms
- SSE 首字节：< 3 秒

### 7.2 可用性
- 系统可用性 > 99%
- 数据备份：每日自动备份
- 错误恢复：服务重启后数据不丢失

### 7.3 安全性
- API Token 认证（可选）
- 用户数据隔离
- 敏感信息（API Key）加密存储
- CORS 配置

### 7.4 可维护性
- 代码模块化，单一职责
- 完整的文档和注释
- 自动化测试（单元测试/集成测试）
- CI/CD 流水线

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| OSM API 不稳定/限流 | 地图生成失败 | 本地缓存 + 多数据源备份 |
| LLM API 成本高 | 运营成本 | 缓存 + 模型降级 + 本地模型 |
| 大区域数据量大 | 生成超时/内存溢出 | 分块处理 + 增量加载 + 地图综合 |
| 知识图谱数据不足 | 制图质量不稳定 | 持续扩充 + 规则兜底 + 用户反馈 |
| 前端渲染性能 | 大量要素卡顿 | Canvas 渲染 + LOD + 虚拟化 |
